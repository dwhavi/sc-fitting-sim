# 2026-11-20 LIVE 패치 점검 및 피팅 반영

## 확인 결과

- 공식 Hotfix Central의 11/19 갱신 기준: LIVE 클라이언트 `13220821`, DGS `13165946`, HOTFIX 채널 닫힘.
- 이번 핫픽스는 Vulkan을 포함한 주요 클라이언트 크래시 3건 수정이다. 공식 내역에 무기·실드·발전기 수치 변경은 없다.
- scunpacked master는 여전히 `f182b7f111279c9193df81927c9b4dbc8c4f3291`, `4.10.3-LIVE.13165946`이다. 클라이언트 번호와 계산 원본 번호를 같다고 표시하지 않는다.
- 5.0 PTU의 TTK 밸런스는 LIVE와 분리한다. 이번 배포에는 PTU 수치를 넣지 않았다.

## 반영

1. 기존 목록에서 빠진 LIVE Drake Marauder 추가, 143 → 144척.
   - 같은 LIVE 덤프와 FleetYards `game_files` 슬롯만 사용.
   - S3 무기 7문, S1 실드 2개, S1 발전기 2개, S2 미사일 랙 2개.
   - 원본 스톡: 버스트 3819.2 DPS, 무기 풀 4핍, 총 소비 21핍, 발전 16핍.
2. 무기 풀 상한을 넘는 개별 무기 소비를 선박 전력에 중복 합산하던 문제 보정.
   - Marauder: 무기 7 → 4핍, 총 소비 24 → 21핍.
   - 풀 공유 함선에서 무기 계통 일부를 끄면 모든 무기를 같은 비율로 조절한다. OFF여도 최대 핍 컬럼은 유지한다.
   - 기존 함선과 부품의 원본 수치는 변경하지 않았다. 재생성 중 기존 누락 Liberator 상부 터렛 1종도 복구했다.
3. 접을 수 있는 패치 정보: 확인 날짜, LIVE 클라이언트, 계산 데이터 버전, PTU 제외, 계산 제약과 공식 링크.
4. 데이터 갱신 안전장치:
   - 한 커밋에 다운로드를 고정하고 임시 스냅샷을 완성한 뒤 교체.
   - 새 패치인데 기존 파일을 건너뛴 채 새 메타데이터로 표시하던 위험 제거.
   - PTU/버전 미확인/부분 실패/미해결 함선 차단. 빌드 검증 실패 시 기존 DB 파일 유지.
   - 보존 부품까지 합친 뒤 meta 개수를 다시 계산. 기존 turrets 메타 329와 실제 464개가 불일치했고, 이번 추가 후 실제 465개로 일치한다.

## 검증

- Python 회귀 테스트: 정상 교체, 다운로드 실패 원본 보존, PTU 차단, 원본 버전 조회 실패, 함선 매핑 실패, 검증 안 된 DB 생성 차단.
- 전력 원본 추출: match 1311, MISMATCH 0, 새 덤프 원본 없는 보존 항목 9.
- 144척 계산 유한값 확인. 총 스톡 전력이 원본과 정확히 일치하는 함선: 96 → 128척.
- Marauder 21/16핍, 7문, 3819.2 버스트, 반 출력, 무기 OFF 컬럼 유지 확인.
- Marauder 추천 5개 프리셋 유한값 및 전력 부족 0 확인.
- 데스크톱 1440px/모바일 390px 실제 브라우저 캡처 확인, JavaScript 오류 0.

## 남은 제약

- 총 스톡 전력 16척 불일치가 남아 있다. 주로 지상차량이며 Valkyrie, Defender, Cutlass Steel, Merlin, Archimedes도 포함한다. 누락 고정 계통, 분수 핍, 실드 풀의 차이 등은 별도 검증이 필요하다. 모든 함선이 게임과 같다고 주장하지 않는다.
- 지속 DPS는 기존 근사 모델을 유지했다. Marauder도 원본 스톡 1952.3 대비 앱 약 1115.6으로 차이가 있으며, 스톡 비교 패널에 표시된다. 이번 수정은 전력 합산 보정이며 DPS 공식 전체 재작성은 아니다.
- 미사일 합계는 개별 스톡 미사일이 아닌 같은 크기 대표 미사일 기준 추정이다.
- 구매처는 기존 UEX 스냅샷이다. 이번에 상점 가격이나 판매 여부를 새로 검증했다는 뜻은 아니다.
- 부품 질량 타이브레이크와 동결 heat/power/powerBase 제약은 그대로다.
