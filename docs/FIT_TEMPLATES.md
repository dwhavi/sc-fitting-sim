# 최적 피팅 템플릿 + 구매처 — 설계 메모

## 왜 이렇게 만들었나
- 기존 Erkul(erkul.games)은 "내가 고른 부품"을 계산하고, 장바구니에서 구매처를 보여준다
  (출처: https://atlasreeve.com/guides/loadout-fitting-erkul/ — "Open the shopping cart ... where to purchase them").
  이 시뮬레이터는 거기서 한 걸음 더: **취향을 고르면 부품 조합을 대신 찾아준다**.
- 구매처 데이터는 UEX Corp(uexcorp.space) 커뮤니티 제보 API를 쓴다. 커뮤니티 도구 목록에서
  UEX와 Cornerstone(finder.cstone.space)이 "어디서 사나" 해결용으로 꼽힌다
  (출처: https://star-citizen.help/guides/getting-started/the-best-star-citizen-tools/).
  Cornerstone 은 동적 페이지라 자동 수집이 안 돼 UEX 하나만 썼다 → 교차 검증 못 함.
- 스텔스는 레이더가 EM·IR(·CS) 신호로 탐지한다는 전제로 EM/IR 합을 줄이는 쪽으로 점수화
  (출처: https://doctrine.substack.com/p/star-citizen-stealth-guide-tutorial). 게임 내 실제 탐지 거리는 계산하지 않는다.

## 화면 구성
1. 왼쪽 패널 "최적 피팅 템플릿" 버튼 → 모달
2. 모달 위에서 아래로: 취향 카드(5) → 구매 조건(지역·예산·교전 거리·구매 가능만) → 결과
3. 결과: 취향 탭으로 5개 결과 전환, 현재 vs 추천 비교표(증감 색), 바뀌는 부품 목록(가격), 어디서 살까(스테이션별 묶음),
   하단 고정 버튼: 이 빌드 적용 / 쇼핑 리스트 복사 / 템플릿 저장
4. 메인 화면 아래 "🛒 구매 목록" 패널: 어떤 빌드든 스톡에서 바꾼 부품의 구매처를 항상 표시
5. 부품 선택 목록·슬롯 버튼에 💰 최저가 뱃지

## 알고리즘
- 평가 함수 = 기존 `fitStats()` (전력 핍, 실드, DPS 등). 취향별 점수 = 현재 빌드 대비 로그비 가중합.
- 탐색: 같은 종류·사이즈 슬롯 일괄 교체 → 슬롯 개별 → (전력 정체 시) 파워플랜트×실드/쿨러 쌍 교체.
  다른 취향 결과도 시작점으로 재탐색해 지역 최적을 피한다. 전체 143척 중 대부분 1~2초.
- 교전 거리: 목표 사거리보다 짧은 무기는 DPS 를 (range/목표)^1.5 로 깎아서 평가 (스캐터건 편중 방지).
- 구매: 스톡 부품은 보유한 걸로 보고 0원, 새 부품만 최저가 합산. 예산은 품목별 최저가 기준.
- 구매 계획: 그리디 집합 커버(스테이션 한 곳에서 가장 많이 사도록) — 최저가와 차이 있으면 표시.

## 한계 (알고 쓰기)
- 카드(마운트·터렛 구조물), 미사일 랙, 추진부는 추천 대상 아님. 터렛 무기는 하위 무기만 추천.
- 전 계통 100% 가동 기준이라 스톡 빌드가 전력 부족으로 나오는 함선이 많고, 그 경우 DPS 증가율이 과장돼 보인다.
- 구매처 데이터는 커뮤니티 제보(최신 제보 날짜가 shops.json meta 에 있음). 이름+사이즈로 매칭하므로 일부 부품은 "구매처 미확인".
- EM/IR 지표는 상대 비교용 값.
