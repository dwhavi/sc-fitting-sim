## 고친 계산

### 1. 에너지 무기의 지속 사격

기존 계산은 부품의 지속 DPS에 무기 풀 비율을 곱했다. 탄수·재충전·발사 시간이 함께 변하는 것을 반영하지 못했다. 일부 대체 경로에서는 같은 비율을 두 번 적용할 수도 있었다.

이제 무기마다 다음 주기를 계산한다.

- 풀 비율 `r = min(1, 선택 무기 핍 / 장착 무기 소비 합계)`
- 탄수 `N = round(최대 탄수 × r)`
- 재충전률 `R = 최대 재충전률 × r`
- 발사 시간 `N / 초당 발사 수`
- 재충전 시간 `쿨다운 + N / R`
- 지속 DPS `N × 탄당 피해 / (발사 시간 + 재충전 시간)`

알파 표시는 원본 발사 모드의 `Alpha`를 우선하고, 캐패시터 주기 계산에는 반올림 전 피해량을 사용한다.

탄수 또는 재충전률이 0이면 지속 DPS는 0이다. 풀 비율을 줄인다고 탄당 피해나 순간 연사력이 줄지는 않는다. 무기 전체 OFF 또는 0핍이면 사격하지 않는다. 탄도 무기는 부품의 지속 사격값을 사용하며, 탄약 총량이 소진된 뒤까지 무한 사격한다는 의미는 아니다.

Marauder의 7문 Panther 예시:

| 항목 | 값 |
|---|---:|
| 선택 무기 전력 / 총 요구량 | 4 / 7 |
| 무기당 탄수 | 43 |
| 무기당 재충전률 | 8.5714발/s |
| 발사 시간 | 3.44s |
| 쿨다운 포함 재충전 | 5.7567s |
| 7문 지속 DPS | 1,428.6 |
| 7문 버스트 DPS | 3,819.2 |

이전 앱의 1,115.6을 1,428.6으로 개선했다. 덤프의 1,952.3은 부품의 풀 제한 없는 지속값 278.9를 7개 합친 수치이므로, 이것에 강제로 맞추지 않았다. 현재 계산도 이상적인 완전 소진·충전 주기 모델이며 실제 조작, 서버 상태, 열화, 손상, 자동 전력 배분을 포함한 인게임 실측값은 아니다.

전력 핍과 캐패시터 줄이 서로 다른 소비량을 만들던 상태도 통합했다. 2핍을 어느 쪽에서 선택해도 같은 전력·지속 DPS를 반환한다. 반 출력에서도 버스트는 유지되고 지속 DPS만 바뀐다.

### 2. 실드·쿨러의 부분 전력

- 실드가 0핍인데도 최대 재생량을 보여주던 문제를 수정했다.
- 최소 작동 핍과 원본 `PowerRanges` 배율을 적용해 실드 재생량을 계산한다.
- 동시 활성 실드 수를 넘는 예비 실드는 HP 합계에는 남지만 추가 재생량을 만들지 않는다.
- 쿨러에도 최소 작동 핍과 출력 구간 배율을 적용했다.
- 서로 단위가 다른 구 열 부하와 현 냉각 자원 출력을 나눠 과열률로 표시하던 계산은 제거했다. 현 냉각 출력만 표시하며 과열 판정은 하지 않는다.

### 3. 슬롯과 부품 누락

- Sukoran은 실제 LIVE 스톡 실드지만 내부 클래스명에 `Placeholder`가 들어가 필터에서 빠졌다. 실제 순정 장착품은 이 필터에서 제외해 복구했다.
- Merlin·Archimedes의 부모 날개 경로가 붙은 슬롯명을 유일하게 대응되는 원본 하드포인트에 연결했다.
- Valkyrie 도어건 2문, Cutlass Steel 도어건 5문을 복구했다.
- 직접 무기와 짐벌 무기가 섞인 Harbinger 체인에서 한쪽 무기가 사라지던 문제를 고쳤다.
- Javelin의 실제 4문 스톡 포탑을 공용 2문 카드 제원으로 잘라내던 문제를 고쳤다. 스톡 카드는 함선의 실제 장착 체인을 우선한다.
- 명시적으로 마운트를 제거하면 하위 스톡 무기가 자동 복구되지 않는다.
- 같은 LIVE 스냅샷으로 기존 슬롯의 순정 부품 19개를 다시 대조했다. 기존 슬롯 ID는 유지해 저장 빌드 키를 보존한다. Razor EX의 발전량도 13이 아닌 원본 16핍이 된다.
- 포탑 베이스 구조물과 고정 유틸 전력을 중복 합산하지 않는다.
